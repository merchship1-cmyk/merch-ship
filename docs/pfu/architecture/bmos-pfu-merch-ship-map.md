## MERCH SHIP runtime binding

- architecture through Architect and CABMM
- experience design through Experience Studio and HI

## Runtime rules

MERCH SHIP must:

1. register every governed capability
2. declare runtime and data boundaries
3. bind every action to an authorized actor
4. follow the BMOS capability lifecycle
5. record evidence for meaningful changes
6. preserve `todo-app/` as the protected Z-001 heritage implementation
7. pass PFU release gates before merge, deployment, production execution, or public release
